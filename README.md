**從 2026/10/26 到 2027/5/16，每一天的每個時段都排好了**，打開網站就知道現在該做什麼。

網址：<https://joshdaaicode.github.io/study-plan/>

## 分頁

**今天 / 日程 / 月曆 / 錯題 / 紀錄 / 獎勵 / 計畫 / 設定**

- **今天**：今天的讀書時段變成可打勾的任務，沒勾的隔天變欠帳、從娛樂時間扣（每天最多扣 60 分、娛樂不低於 30 分）。每段任務下面寫了做法。
- **日程**：每日詳細日程。左右切換日期（手機可以左右滑）、點日期條或用日曆跳到任何一天；現在正在進行的時段會標「現在」，今天勾掉的會打勾。網址加 `#d=2027-1-27` 可以直接打開那一天。
- **月曆**：考試、假日、補習、資優數學都標好了，點格子可以加記事，也可以跳到那天的日程。
- **計畫**：雙軌時間軸、六個階段、時段模板、還沒定案的變數、科班與會考進度表。

## 要改日程時

- **只改某一天**：到「今天」按「編輯今天的日程」，只影響那一天，可隨時「恢復預設」。
- **整段重排**（簡章公布、雄中考古題本到了、寒輔日期確定）：改 `tools/gen_plan.py` 開頭的行事曆（`EXAM`、`HANFU`、`HOLIDAY`、`CRAM_LAST`、`GIFTED_LAST`）或教材，然後執行

  ```
  python tools/gen_plan.py
  ```

  會重新寫出 `plan.js` 並印出各階段的時間分配與每項教材排到哪一天。改 `VERSION` 可以讓手機上的「今天」重新產生。

## 雲端同步

「設定 → 雲端同步」用自己的 GitHub Gist 當資料庫，換裝置不用重填。
Token 只存在該裝置的 localStorage，不會寫進網頁原始碼；權限只勾 **Account permissions → Gists → Read and write**。
**Token 不要貼到任何聊天視窗。**

- 新裝置只要貼 token：會自動找到原本的備份 Gist，問一次要不要下載，自動同步預設開啟。
- 這台上次同步後沒改過、雲端又比較新（另一台傳的）→ 打開網站或切回來時自動下載；兩邊都改過 → 停下來讓你選，不會互蓋。
- 一有改動約 2 秒內就上傳（2026-11-07 起；連續改動併成一次，兩次上傳至少隔 10 秒），切到背景或關分頁時馬上傳；上傳途中再改的，傳完馬上補傳。剛打開網站、正在看雲端有沒有別台的新資料時，先等它看完再傳。
- 還原快照、匯入、下載雲端前都會先另存一份「還原前」快照，可以反悔。
- 沒設定雲端同步的裝置每天提醒一次（資料只在那台，清瀏覽器資料就沒了）。

## Claude 補登連結（11-07）

## 其他功能

**單字賭場**（2026-11-02）：範圍選會考 2000 字（基本／進階）、片語、多益 Level 1～5、錯字本，可以只考某些字母或詞性（康軒課本之後加入）。倍率＝題型（簡單 ×1.5、普通 ×2、困難拼字 ×3、地獄聽音拼字 ×5）× 單字難度（多益 Lv1～5 ×1.5／2／3／4／5）；連對 3 次的熟字只有 ×1。六種玩法：一局 10 題、一題一注、加倍爬梯、限時衝刺、跟寵物對賭、拉霸轉倍率；押點數、籌碼或 🌟。讀書時段、今天任務不到一半、點數負的或欠銀行都不能下注；一次最多押「50＋今天讀書分鐘」。答錯的字進錯字本（隔 1、3、7 天再考，連對 3 次移出），錯字本複習算英文讀書分鐘，滿 25 分鐘種一棵英文番茄樹。籌碼可以換寵物帽子、稱號、賭場背景。

寵物新增：番茄鐘掉寶、天賦（理財／旅行／單字）、寵物日記。銀行新增：科目股（股價跟著那科前 7 天的完成率）、自動存款、存錢目標。

我的森林與寵物（8 種自己畫的寵物，會走路、眨眼、搖尾巴、吃飯、玩球、表演把戲；天氣跟照顧掛勾、日夜變化；任務種樹、旅行寄明信片；1 天沒照顧不理你、2 天生病、5 天離家）、森林銀行（活存只在有照顧的日子生利息、定存、押自己成績的考試定存、預支與信用等級、🌟／🍀／🎟️ 兌換）、成就（33 個五階成就＋8 個隱藏成就，領獎給點數、🌟、稱號、家具）、點數加成（連續照顧、今日加成、幸運 ×2）、分科進度與科班考古題配速、教材進度自動算、日程搜尋、段考加權平均、錯題本（費氏或固定間隔複習）、番茄鐘與時段提醒、每日日誌與心情、進度回測、成績與配速紀錄、許願商店與自己訂的獎勵、要問老師清單、今天狀況不好（降級模式）、教材對照、匯出手機行事曆（.ics）、本機快照、配色主題（天空藍預設，可依考試急迫性自動換色、入夜轉深色）。
