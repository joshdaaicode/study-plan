# 國三雙軌作戰計畫

雄科班（3 月初試）＋ 國中教育會考（5/15–16）的雙軌讀書計畫。
所有日期、倒數、階段標示與月曆都依**開啟當天**自動計算，跨日會自動重算。

\---

## 一、放上 GitHub Pages

手機或電腦都能操作，全程在瀏覽器裡完成，不需要安裝 Git。

1. 登入 GitHub → 右上角 `+` → **New repository**
2. Repository name 填 `study-plan`，選 **Public**，按 **Create repository**
3. 進入 repo → **Add file** → **Upload files**
4. 把 `index.html` 和 `manifest.json` 兩個檔案拖進去 → **Commit changes**
5. 上方 **Settings** → 左側 **Pages**
6. Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/ (root)** → **Save**
7. 等 1–2 分鐘，網址會出現在同一頁：

```
https://<你的帳號>.github.io/study-plan/
```

> 檔名一定要是 `index.html`，Pages 才會自動載入。

### 加到手機主畫面

用手機瀏覽器開上面的網址：

* **iPhone（Safari）**：分享鈕 → 加入主畫面
* **Android（Chrome）**：右上選單 → 加到主畫面

之後點圖示會全螢幕開啟，看起來就像一個 App。

### 注意

Public repo 的內容是公開的（任何人知道網址就能看）。裡面只有讀書計畫，沒有個資，但如果介意，
可以把 repo 命名成不好猜的名字，或改用 GitHub Pro 的私人 repo + Pages。

## 二、要改東西時改哪裡

全部在 `index.html` 裡，用 GitHub 網頁版的鉛筆圖示就能直接編輯，存檔後 1 分鐘內自動更新網站。

### 科學班日期（**一月拿到簡章後一定要改**）

目前是依歷屆時程推估的。搜尋 `EVENTS`，改這幾行：

```js
\[3,13,'雄科班初試',1],
\[3,20,'雄科班複試',1],
```

格式是 `\[月, 日, '名稱', 是否為推估]`。確定日期後把最後的 `1` 改成 `0`，畫面上的「推估」字樣就會消失。

同時搜尋 `MARKS`，改月曆上的標記：

```js
\[2027,3,13,'p-s','初試?'],
\[2027,3,20,'p-s','複試?'],\[2027,3,21,'p-s','面談?'],
```

格式是 `\[年, 月, 日, 樣式, 標籤]`。確定後把標籤裡的 `?` 拿掉。

還要改頂部倒數：搜尋 `c-sci`，把 `mk(3,13)` 換成實際日期。

### 段考日期（學校公布正式版後）

搜尋 `MARKS`，找到 `'一段'`、`'二段'`、`'三段'` 那幾行改日期。
時間軸區塊的文字要另外改，搜尋 `10/12–13` 之類的字串。

### 整段佔用上午的課程（暑輔之類）

暑輔已經上完，所以目前是空的。之後如果有寒輔、輔導課這類整段佔掉上午的安排，搜尋 `SUMMER`，把日期填進去：

```js
var SUMMER = \['2027-1-21','2027-1-22'];
```

格式是 `'年-月-日'`。填完之後，月曆會自動標上橘色標記，逐日表對應那幾列也會自動改成
「上午上課、科學班順延到 18:30–21:00、當天不排會考」，不用手動改表格。

### 畢旅 / 假日

畢旅暫定 10/14–16（段考隔天出發），確定後搜尋 `'2026-10-14'` 改日期即可。

### 寒輔日期（12 月拿到通知後要改）

目前暫定 1/21–1/29。搜尋 `SUMMER`：

```js
var SUMMER = {
  '2027-1-21':'寒輔','2027-1-22':'寒輔', ...
};
```

改完月曆會自動更新。寒假本身是 1/21–2/10，其中 2/4–2/10 為春節。

### 國定假日

已依人事行政總處 115／116 年辦公日曆表填好（2026/9 中秋 \~ 2027/5 勞動節）。假日當天整天跳過，
月曆會標紅字，也不顯示補習與輔導。要增減搜尋 `HOLIDAYS`，格式 `'年-月-日':'名稱'`。

補習班是否在連假停課請自行確認；學校行事曆由各縣市教育局另訂，可能微幅不同。

### 新增一個行程

在 `MARKS` 陣列裡加一行就好，例如：

```js
\[2027,2,25,'p-w','報名截止'],
```

可用的樣式：
`p-b` 淡紫（補習）、`p-g` 灰（資優數學）、`p-m` 淡綠（模考段考）、
`p-s` 紫底白字（科學班考試）、`p-x` 綠底白字（會考）、`p-w` 橘（提醒）

## 三之一、「今天」分頁怎麼用

* **勾選**：完成一項就勾掉。沒勾的在隔天會自動變成「欠帳」排進來。
* **欠帳扣娛樂**：欠帳的分鐘數會從當天娛樂時間扣掉，但**每天最多扣 60 分、娛樂不低於 30 分、睡眠一律不動**。
* **欠帳超過 90 分**會跳提示，建議直接按「清掉欠帳」重來並砍任務，而不是一直累積。
* **＋ 新增任務**：加當天的臨時任務。
* **編輯這類日子的範本**：改動會套用到所有同類型的日子（暑假平日、學期週三、寒假週末……共九種）。可隨時「恢復預設」。
* 資料存在瀏覽器的 localStorage，只在這台裝置上；換裝置或清除瀏覽資料會重來。

### 番茄鐘與時段提醒

「今天」分頁最上面有一張卡：

* **左邊**顯示現在時間，並依當下時刻自動判斷「現在應該在做什麼」、還剩幾分鐘、下一個區塊是什麼。
* **右邊是番茄鐘**：專注時間可選 15/20/25/30/40/45/50 分，休息 3/5/10/15 分，連續四顆後自動變成 15 分長休息。計時中分頁標題會顯示剩餘時間，切到別的 App 也看得到。
* **開啟時段提醒**：按一次授權後，每個區塊開始時、以及下一個區塊開始前 5 分鐘會跳通知並發出提示音。瀏覽器不給權限的話會改用畫面底部的橫幅，一樣會響。
* 今天完成幾顆番茄鐘會記錄下來，跨日自動歸零。

提示音用瀏覽器內建音訊產生，不需要額外檔案；手機要先點過畫面（例如按「開始」）才會有聲音，這是瀏覽器的限制。

### 成績紀錄

每次段考模考完，在「成績」分頁填國數英自社和作文級分，按儲存。
填滿兩次以上會自動畫出平均分走勢圖。單次分數看不出東西，連續三次同方向才算趨勢。

### 許願商店

完成一項任務 +5 點、一顆番茄鐘 +5 點、當天全清 +15 點。

考試在「成績」分頁的「小考／大考登記」填分數，點數自動加減：

|類型|規則|
|-|-|
|資優小考|≥50 +10、≥90 +20、100 +40|
|一般小考|≥90 +15、<70 −10、<60 −20|
|大考（段考模考）|≥90 +20、100 +40|

所有數值都能在「設定 → 點數規則」改。商店品項和價格可增刪，搜尋 `DEFSHOP` 可改預設。

### 設定與備份

* **自訂日程**：暑假／學期／寒假 × 週日到週六，共 21 種範本各自獨立，在「今天」按「編輯這類日子的範本」修改。編輯器下方可勾**套用到哪幾天**，一次改好幾個星期。
* **月曆記事**：在「日程」分頁點任何一天，可以加標題和記事，會顯示在月曆格子和「今天」。
* **例假日精簡模式**：目前週末只留補習，科學班倒數進入 200 天以內（2026/8/25）自動切回完整行程。門檻搜尋 `BIND\_AT`。
* **補習班停課日**：搜尋 `CLOSED`，格式 `'年-月-日':1`。目前是 8/22、8/29、8/30。
* **備份**：「設定」分頁可匯出文字、下載成 JSON 檔、或貼回匯入。
* **雲端同步**：用你自己的 GitHub Gist 當資料庫，換裝置不用重填。

#### 雲端同步怎麼設定

1. GitHub 頭像 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
2. 名稱隨意，Expiration 建議 1 year
3. Repository access 選 **Public Repositories (read-only)**
4. 往下找 **Account permissions**（不是 Repository permissions）→ **Gists** → **Read and write**。其他全部 No access
5. Generate token，複製那串 `github\_pat\_...`（只會顯示一次）
6. 網站 → 設定 → 雲端同步 → 貼上 token → 按「測試連線」→ 按「上傳到雲端」

Gist ID 留空，第一次上傳會自動建立一個 **secret gist** 並記住 ID。
之後換裝置時，貼上同一組 token 和 Gist ID，按「從雲端下載」就還原了。

**Token 只存在該裝置的 localStorage，不會寫進網頁原始碼**，所以 public repo 看不到。
勾「自動同步」後，資料有變動會在 30 秒內自動上傳，關閉分頁時也會補傳一次。

token 萬一外洩，因為只有 Gist 權限，別人也只能看到你的讀書計畫備份，動不了 repo 或帳號。
真的擔心就到 GitHub 把那個 token 刪掉重建。
