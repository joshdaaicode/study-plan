五個階段

配比會變，睡眠不變

同樣一週 26 小時的可支配時間，五個階段的分法完全不同。色條是大致比例，不是要你拿碼表計時。

PHASE 18/17 – 8/27
剩 11 天

研發衝刺：這 11 天是全年唯一的開發窗口

8/28 返校，之後到明年五月，開發時間等於零。所以每天下午 13:30–17:30 整塊給研發，共約 43 小時——這是你今年能拿到的全部。上午整段給科學班（高一數理沒人會替你上），晚上輕量掃 9/8 一模的 1–2 冊。

PHASE 28/28 – 1/20
返校後

雙軌並行：讓模考當你的複習排程

開發歸零，原本那 3.5 小時全數轉給科學班——這正好補上三月初試的缺口。一模到三模的範圍是層層疊加的（1–2 冊 → 1–4 冊 → 全科 1–4 冊），本身就是一份現成的分散複習表，照著走舊冊自然會被反覆撿回來。段考前一週切換成 C 版週表。

PHASE 31/21 – 3/21
寒假 → 初試

科學班衝刺：寒假比你以為的短很多

寒假只有 1/21–2/10，其中 2/4–2/10 全是春節，再扣掉寒輔佔掉的上午——真正能用的大約兩週的下午與晚上。所以地科自學和考古題不能等寒假，要提前到 11–12 月的週末和 12/25、1/1 兩段連假。寒假的角色從「打進度」降級成「密集練考古題」。會考降到每天 45 分鐘維持不斷線，四模考差一次不會怎樣。

PHASE 43/22 – 5/16
會考衝刺

乾淨切換：放榜那天起，科學班歸零

不論結果如何，3 月底之後不要再回頭碰科學班的東西。八週衝會考聽起來短，但你前面為了科學班練的數理深度，會直接兌現成分數。這階段主軸是錯題本三輪＋歷屆限時，不是再讀新內容。

PHASE 55/17 →
會考後

把時間還給你自己

停了九個月的開發從這裡重新開始。八月留下的 README 和待辦清單，就是給這一天的自己看的。同時可以開始預習高一——但這是紅利，不是義務。

彈性時間

計畫排到 85% 就好

九個月裡一定會掉進度——生病、颱風假、學校臨時活動、社團的事、單純那天狀態很差。排滿的計畫第一次被打斷就會全面崩潰，所以緩衝要事先留好，不是事後硬擠。

  • 01
    每週：週六 13:00–15:00 機動區

    預設拿來寫科學班考古題。但只要這週有掉進度，這 2 小時就改去補——補完才回到預設。這是唯一一格「可以被進度佔用」的時間。

  • 02
    每週：週日 15:00–16:20 完全空白

    這格不准被任何理由佔用，包含補進度。它的作用就是讓你知道「再怎麼欠帳，還是有一段時間屬於自己」。

  • 03
    每次模考後：隔週一整晚只做訂正

    模考的價值全在訂正，不在分數。這一晚不排新進度，把錯題本補完就結束。

  • 04
    每個大關卡後留一天緩降

    畢旅回來當天、段考結束當天、初試結束當天、複試結束當天，都不排進度。硬排的結果是隔天更爛。

  • 05
    掉的進度從機動區補，不從睡眠補

    如果連續兩週機動區都補不完，那不是你不夠努力，是計畫排太滿——直接砍掉當期優先度最低的那一項，不要靠熬夜硬撐。

讀書方法

選效果最強的那兩種就好

兩份大規模統合分析（Dunlosky 等人 2013；Hattie 與 Donoghue 2021，涵蓋 242 項研究、逾 16 萬名參與者）得到同樣的結論：分散練習與測驗式練習是所有讀書技巧中效果最強的兩項。其餘的可以不管。

提取，而不是重讀

闔上書本先默寫你記得的，再打開對答案。重讀和劃線感覺很順，但那是熟悉感不是記憶。每個讀書區塊的最後 10 分鐘拿來做這件事。

分散，而不是集中

同樣五小時，分五天各一小時遠勝一天讀完。你的模考範圍已經內建這個結構了。

交錯，而不是分堆

一節課裡混著練不同題型，比連做二十題同類型難、但學得牢。段考前尤其要這樣練。

錯題本是你的私人題庫

整年最有價值的一本。只收「訂正過還會再錯」的題，每題寫一行「我當時為什麼會錯」。四月的第三輪就靠它。

三條不能破的底線

  • 01
    睡滿 7.5–8 小時

    記憶是在睡覺時固化的。熬夜多讀的那兩小時，會從隔天的吸收效率裡扣回去，而且扣得更多。這是整份計畫裡唯一一條完全不能談判的。

  • 02
    每週三次、每次 30 分鐘以上的身體活動

    不是奢侈品。連續九個月的高強度腦力工作，運動是維持專注力和情緒穩定的必要成本，不是可以省下來的時間。

  • 03
    每週一個完全空白的時段

    週五晚上第二區塊＋週日下午 15:00–16:20。不排讀書、不排補進度、不欠帳。撐九個月靠的是可持續，不是靠某一週特別拚。
